E-commerce Data Analysis Project (Olist Store) 📊
Project Overview
This project focuses on analyzing the Olist E-commerce dataset to extract meaningful business insights. I transitioned from raw, fragmented data into a fully interactive dashboard that tracks sales performance, customer behavior, and logistics.
Tools Used
Excel: For data visualization and dashboarding.
Power Query: For Data Cleaning, Transformation, and Merging multiple datasets.
Key Steps Performed
Data Integration: Merged the Orders dataset with the Products dataset to create a unified view.
Data Cleaning: * Handled missing values and inconsistent data types.
Removed duplicates to ensure data integrity.
Formatted currency and date columns for accurate analysis.
Data Visualization: Built an interactive dashboard featuring:
Top Selling Categories: Identifying which products drive the most volume.
Revenue Analysis: Calculating total sales per category.
Shipping Analysis: Understanding the average freight value across different product types.
